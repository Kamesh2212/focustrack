# Code of Conduct

FocusTrack is about wellbeing, and that includes the people building it.

## Our standards

- Be respectful and kind, including when you disagree. Critique ideas and code, not people.
- Welcome newcomers and assume good intent. Everyone was new once.
- Be patient and explain context; link to docs instead of saying "just".
- No harassment, discrimination, personal attacks, sexualised content, or sharing others' private
  information.
- Respect privacy: this project handles sensitive usage data, so treat users' data, and each other, with care.

## Scope

This applies in issues, pull requests, discussions and any other project space, and when representing the
project elsewhere.

## Enforcement

Report problems privately to the maintainers through GitHub (Security → Report a vulnerability works for
conduct reports too) or by contacting a maintainer directly. Maintainers will review every report, keep it
confidential, and may remove content or block participants who don't follow this code.
